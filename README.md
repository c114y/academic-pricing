# 学术论文服务报价查询系统

这是一个专为学术服务机构开发的在线报价查询系统，支持移动端访问，无需VPN即可直接浏览。

## ✨ 功能特性

- 📱 **移动端优先设计**：完美适配手机、平板和电脑
- 🎯 **智能联动**：自动根据学历、专业调整可选服务
- ⚡ **实时报价**：输入信息后立即显示价格
- 🚫 **智能拦截**：特殊需求自动提示咨询售前顾问
- 🎨 **美观界面**：现代化UI设计，操作简单直观

## 📋 使用说明

### 在线使用

直接访问网页链接，按照以下步骤操作：

1. **选择学历层次**：选择您的最高学历
2. **选择专业类型**：选择论文所属专业类别
3. **选择服务类型**：选择纯文字、数据分析或系统开发
4. **填写详细要求**：
   - 计划字数（默认8000字）
   - 查重率要求（默认20%）
   - AI率要求（默认20%）

### 联动规则

系统会自动根据您的选择进行调整：

- **专科/函授**：仅支持纯文字服务，无法选择数据分析或系统开发
- **计算机专业**：仅支持系统开发服务
- **硕士及以上**：显示"请咨询售前顾问"
- **理工/农学/其他专业**：显示"请咨询售前顾问"
- **查重率或AI率低于15%**：显示"请咨询售前顾问"

## 🚀 本地开发

### 环境要求

- Node.js 24+
- pnpm

### 安装依赖

```bash
pnpm install
```

### 启动开发服务器

```bash
pnpm dev
```

访问 http://localhost:5000

### 构建生产版本

```bash
pnpm build
```

### 启动生产服务器

```bash
pnpm start
```

## 📦 部署到线上

### 方案A：Vercel（推荐，免费）

1. 将代码上传到 GitHub
2. 访问 [Vercel](https://vercel.com)
3. 点击 "New Project"
4. 选择你的 GitHub 仓库
5. Vercel 会自动检测 Vite 项目并配置构建命令
6. 点击 "Deploy" 即可

### 方案B：Netlify（免费）

1. 将代码上传到 GitHub
2. 访问 [Netlify](https://netlify.com)
3. 点击 "Add new site" → "Import an existing project"
4. 连接你的 GitHub 仓库
5. 构建设置：
   - Build command: `npm run build`
   - Publish directory: `dist`
6. 点击 "Deploy site"

### 方案C：静态服务器

1. 构建项目：`pnpm build`
2. 将 `dist` 目录上传到任何静态服务器（如阿里云OSS、腾讯云COS）
3. 配置域名访问
